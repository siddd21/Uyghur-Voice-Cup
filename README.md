# The Uyghur Voice Cup – Kaggle Competition

This repository contains my solution for the [The Uyghur Voice Cup](https://www.kaggle.com/competitions/the-uyghur-voice-cup/overview) competition on Kaggle.

---

## Competition Overview
This competition challenges participants to build voice processing models (e.g., speech recognition, speaker identification) for the Uyghur language — a less-resourced language.  
The goal is to develop high-quality models that generalize well across speakers, recording conditions, and dialects.  
The metric and full rules can be found on the Kaggle competition page.
