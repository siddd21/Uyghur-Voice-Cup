# Uyghur Automatic Speech Recognition (ASR) Challenge

This repository contains my solution for the [Uyghur ASR Challenge](https://www.kaggle.com/competitions/the-uyghur-voice-cup/overview) competition on Kaggle.

---

## Competition Overview
The **Uyghur Automatic Speech Recognition (ASR) Challenge** tasks participants with building a high-performing ASR system capable of accurately transcribing **Uyghur-language audio clips**.  
The dataset provides over **23 hours of speech**, allowing participants to train models that can convert spoken Uyghur into text with high accuracy.
